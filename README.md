# Kaavu Healthcare — Premium Website

## Run
1. Extract this ZIP.
2. Open CMD in the folder containing `package.json`.
3. Run:
   `npm install`
4. Run:
   `npm run dev`
5. Open `http://localhost:3000` in Chrome/Edge.

## Included
- Premium responsive healthcare landing page
- Scroll reveal animations
- Medical-themed animated visuals
- AI assistant route
- Dashboard with creator/contact details
- LinkedIn, GitHub, Instagram and email links
